# ISO 9001

Praba menggunakan ISO 9001 sebagai referensi pengembangan sistem manajemen mutu dan tidak menyatakan memiliki sertifikasi.

Sumber resmi: https://www.iso.org/standard/9001

Registri internal: `SRC-ISO-9001-001`.

Per September 2026, ISO mencatat ISO 9001:2026 sebagai edisi ke-6 dan menggantikan ISO 9001:2015.
