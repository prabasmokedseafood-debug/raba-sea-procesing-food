# ISO 14001

Praba menggunakan ISO 14001 sebagai referensi pengembangan sistem manajemen lingkungan dan tidak menyatakan memiliki sertifikasi.

Sumber resmi: https://www.iso.org/standard/14001

Registri internal: `SRC-ISO-14001-001`.

Per September 2026, ISO mencatat ISO 14001:2026 sebagai edisi ke-4.
