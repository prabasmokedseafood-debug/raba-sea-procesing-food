# Sumber Gambar

Registri utama berada di `sources/image-sources.json`.

Aturan:
- Foto internet harus memiliki URL, tanggal akses, lisensi/penggunaan, dan kredit bila diperlukan.
- Foto milik Praba dicatat sebagai `owner-provided`.
- Gambar AI dicatat sebagai `ai-generated` dan pada publik diberi keterangan bahwa gambar bukan foto aktual Praba.
- Placeholder foto Juwana tidak boleh diisi URL palsu.
