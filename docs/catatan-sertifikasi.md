# Catatan Sertifikasi

Praba Smoked Seafood saat ini belum menyatakan memiliki sertifikasi ISO 9001 maupun ISO 14001.

Kedua standar digunakan sebagai referensi pengembangan sistem. Referensi resmi saat ini:
- ISO 9001:2026 — https://www.iso.org/standard/9001?browse=ics
- ISO 14001:2026 — https://www.iso.org/standard/14001

Jangan menampilkan klaim sertifikasi tanpa bukti resmi dari pemilik/dokumen sertifikasi.
