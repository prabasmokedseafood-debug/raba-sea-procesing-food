# V9 — Tentang Kami Maksimal

V9 mempertahankan fondasi V7/V8: JSON sebagai sumber data, tiga bahasa, Source Registry, placeholder gambar, dan pemisahan data wilayah dari informasi Praba.

## Peningkatan
- Editorial command rail untuk navigasi bagian panjang.
- Reading progress bar.
- Skip-link aksesibilitas.
- Bagian manifesto/positioning yang menjelaskan prinsip mutu tanpa klaim sertifikasi.
- Reveal animation berbasis IntersectionObserver.
- Dukungan `prefers-reduced-motion`.
- Hover states yang lebih halus untuk kartu data, mutu, keamanan, ISO, cold chain, FIFO, dan referensi.
- Hero image micro-interaction.
- Translation keys baru dimasukkan ke `data/translations.json`.

## Prinsip yang dipertahankan
- Tidak menyebut Praba tersertifikasi ISO 9001/14001.
- Data aktivitas Juwana tetap bukan kapasitas Praba.
- Ilustrasi tidak dipresentasikan sebagai foto aktual fasilitas Praba.
- Pemeriksaan visual ikan tidak dipresentasikan sebagai pengujian keamanan pangan.
- Angka rantai dingin dari sumber eksternal tetap disebut sebagai referensi, bukan SOP internal Praba.
