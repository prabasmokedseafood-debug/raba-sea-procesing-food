# Dokumentasi V7

V7 memisahkan konten publik dari data dan registri sumber. Konten yang berubah secara rutin sebaiknya dikelola melalui JSON, sedangkan Source ID digunakan untuk pelacakan internal.

## Urutan pengelolaan

1. Tambahkan atau perbarui sumber.
2. Catat Source ID.
3. Perbarui data JSON.
4. Pastikan periode/satuan/konteks tersedia untuk angka.
5. Pastikan gambar memiliki Source ID.
6. Jalankan validasi.
7. Jalankan website melalui Live Server.
